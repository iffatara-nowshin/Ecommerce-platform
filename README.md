# 🛒 Ecommerce Platform (React + Django)

## 📌 Project Overview
This is a full-stack ecommerce web application built using **React (Frontend)** and **Django (Backend)**.
The system allows users to browse products, manage cart, and perform basic ecommerce operations.

## 🚀 Features
* User registration & login
* Product listing
* Add to cart functionality
* Backend API using Django
* Responsive frontend using React

## 🛠️ Tech Stack

**Frontend:**
* React.js
* Axios
* CSS / Bootstrap (if used)

**Backend:**
* Django
* Django REST Framework

**Database:**
* SQLite (default) / PostgreSQL (optional)


## 📂 Project Structure

```
Ecommerce-platform/
├── frontend/   # React App
├── backend/    # Django Project
```


## ⚙️ Installation & Setup

### 🔹 Backend (Django)
```bash
cd backend
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

### 🔹 Frontend (React)
```bash
cd frontend
npm install
npm start
```

## 🌐 API Integration
Frontend communicates with backend using REST APIs.
